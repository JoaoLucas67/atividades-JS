## 📚 Sobre o projeto

Este projeto reúne exercícios desenvolvidos com o objetivo de praticar os conceitos fundamentais de JavaScript, utilizando HTML e CSS para criar páginas interativas.

## 🚀 Atividades desenvolvidas

| Exercício | Descrição |
|:---:|---|
| **01** | 📝 Programa Meu Nome |
| **02** | ➕ Soma de Números |
| **03** | ➖ Subtração de Números |

### 📝 01 - Programa Meu Nome
Permite que o usuário digite seu nome e apresenta uma mensagem personalizada na tela.

### ➕ 02 - Soma de Números
Recebe dois números, realiza a operação de adição e apresenta o resultado.

### ➖ 03 - Subtração de Números
Recebe dois números, realiza a operação de subtração e apresenta o resultado.
